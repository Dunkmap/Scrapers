Quick answer

Amazon Product Scraper turns any Amazon search, category or product URL into full product records with 55 fields: price and list price, ASIN, stars and star breakdown, bestseller ranks, sellers, variants, images and delivery dates. It works on 24 Amazon marketplaces with no login and no Amazon API key, and costs $1 per 1,000 products, or $0.20 per 1,000 for search-grid data only. Error rows are never charged.

  1. 1Open Amazon Product Scraper on Apify.
  2. 2Paste search, category or product URLs.
  3. 3Set Max results per start URL, and optionally a postcode, sellers or variant prices.
  4. 4Run it and export JSON, CSV, Excel or XML.

Three kinds of Amazon URL work:

URL typeExample

An example input: one search on amazon.com and one product on amazon.de, priced for a New York delivery address, with seller details:

{
  "categoryOrProductUrls": [
    { "url": "https://www.amazon.com/s?k=mechanical+keyboard" },
    { "url": "https://www.amazon.de/dp/B0D14N2QZF" }
  ],
  "maxItemsPerStartUrl": 50,
  "zipCode": "10001",
  "scrapeSellers": true
}

Scrape Amazon products with Python

Install the client with pip install apify-client, then start a run and read the products. Replace YOUR_APIFY_TOKEN with the token from your Apify account settings.

from apify_client import ApifyClient

client = ApifyClient("YOUR_APIFY_TOKEN")
run = client.actor("molded_mountainpass/amazon-product-scraper").call(run_input={
    "categoryOrProductUrls": [{"url": "https://www.amazon.com/s?k=mechanical+keyboard"}],
    "maxItemsPerStartUrl": 50,
})

for product in client.dataset(run["defaultDatasetId"]).iterate_items():
    print(product["asin"], product["price"], product["title"])

The same run works from JavaScript, from a plain HTTP request to the Apify API, or from n8n, Make and Zapier without code.

Limits worth knowing

  • One offer per product. The featured (buy box) offer is included. Other sellers' offers are not returned yet.
  • Review insights, not every review. You get the star breakdown and Amazon's AI review summary, not each review's text.
  • Amazon caps some searches at 7 pages. Use a category URL, or a category plus a search term, to go deeper.
  • Prices follow the delivery address. Two runs from different locations can show different prices, so set a postcode when you compare.

Frequently asked questions

Is there an Amazon product API I can use without a key?

The official Amazon Product Advertising API needs an approved affiliate account and a key. Amazon Product Scraper reads the public product pages instead, so it needs no key, no login and no cookies, and it returns fields the official API does not, such as bestseller ranks, the AI review summary and seller business details.

How much does it cost to scrape 1,000 Amazon products?

$1 for 1,000 full product records with all 55 fields, plus $0.00005 per run. With product details switched off you get the search-grid fields for $0.20 per 1,000. Error rows are never charged.

Which Amazon marketplaces does it support?

24: amazon.com, .co.uk, .de, .fr, .it, .es, .nl, .se, .pl, .com.be, .ie, .com.tr, .ae, .sa, .eg, .in, .sg, .co.jp, .com.au, .ca, .com.mx, .com.br, .cl and .co.za. Each returns its own language, currency and delivery dates.

Can I scrape Amazon products with Python?

Yes. Start a run with the apify-client package and read the results as JSON, as shown above. JavaScript and plain HTTP work the same way.

Can it scrape a whole Amazon category?

Yes. Paste the category URL and raise the result limit. Amazon caps some bare search terms at 7 pages; a category URL, or a category combined with a search term, goes deeper.

Can I get prices for a specific postcode?

Yes. Set a ZIP or postal code and the prices, stock and delivery dates are the ones that address sees, at no extra charge.

Does it scrape Amazon reviews?

It returns review insights: the star breakdown, review count and Amazon's own AI review summary with sentiment per aspect and the quoted reviews behind it. Review-by-review scraping is not included.

Is scraping Amazon product data legal?

The Actor reads publicly visible product pages, needs no login and collects no personal data. How you use the data is your responsibility, so check the rules that apply to you before republishing it.
