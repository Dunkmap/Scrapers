How to use it

From an open tab to a spreadsheet, in five steps

The extension is free and takes about three minutes to set up. You only do steps 1 and 2 once.

  1. 1Install Ultimate Data Scraper from the Chrome Web Store and pin it to your toolbar.
  2. 2Open the Account tab and paste your Apify API token. The pill at the top changes from Not connected to your Apify username.
  3. 3Open the page you want to scrape, then open the extension. It reads the tab's address and shows it under On this page.
  4. 4Under Choose a scraper, pick a category — E-commerce, Social media, Trending or Jobs — and then the scraper.
  5. 5Check the fields, read the price line above the button, and click Run scraper. Download from the Runs tab when it finishes.

Filling in a scraper

Picking a scraper opens its form. The example below is Amazon Search Scraper, but every scraper works the same way:

  • Prefilled from your tab. If the page you have open fits the scraper, its keywords, URL or marketplace are already filled in.
  • Details opens that scraper's full documentation on Apify, so you can read what each field does.
  • Advanced holds the options most runs never need — proxies, languages, delivery postcodes and the like.
  • The price line sits just above the button and names the cost per 1,000 of each thing that scraper charges for, before you run anything.
  • ‹ All scrapers takes you back to the list without losing your place.
The extension reads only the address of the tab you have open, to pick the right scraper and prefill it. It never reads the page's content, your other tabs or your history.

What it costs

The extension is free; Apify charges for results

There is no subscription and no licence for the extension itself. The scrapers run on Apify under your own account and draw on your Apify credit, exactly as they would if you opened them on apify.com.

  • Apify's free plan includes monthly credit, which is enough to try every scraper in the popup.
  • Each scraper's price per 1,000 results is printed above the Run scraper button before you run it.
  • You pay for results, not for time. Rows that fail are not charged.
  • New to Apify? Create a free Apify account, then copy the token from Settings → Integrations.

FAQ

Common questions

Does Ultimate Scraper need an Apify account?

Yes. The extension is free, but the scrapers run on Apify's cloud under your own account, so you paste your Apify API token once in the Account tab. Apify's free plan includes monthly credit, which is enough to try every scraper.

Does it use my logins or cookies?

No. The scrapers run in Apify's cloud, not in your browser, and they read public pages without any login. The extension reads the address of the tab you have open to pick the right scraper, not the page's content.

Where is my Apify token stored?

Only in Chrome's local extension storage on your own device. It is sent only to api.apify.com to start your runs and fetch your results, never to the developer. Click Disconnect in the Account tab to delete it. The privacy policy has the full detail.

What does it cost?

The extension itself is free. You pay Apify for the results each scraper returns, from your own Apify credit. The price per 1,000 results is shown in the extension, just above the Run scraper button, before you run anything.

Can I use the same scrapers without the extension?

Yes. Every scraper in the extension is an Apify Actor you can open and run directly on apify.com, or call from Python, JavaScript, the Apify API, n8n, Make or Zapier. The extension is a shortcut, not a separate product.

Why does it say "Not connected"?

That is the state before you add a token. Open the Account tab and paste your Apify API token; the pill then shows your Apify username. If it still says Not connected, the token was probably copied with a missing character — copy it again from Apify's Settings → Integrations.
